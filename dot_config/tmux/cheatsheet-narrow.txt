       TMUX CHEATSHEET
       ══════════════

 SESSIONS
 ────────
 prefix + d     Detach
 prefix + s     List sessions
                (sorted by name)
 prefix + S     Pick & rename
 prefix + $     Rename session
 prefix + (     Prev session
 prefix + )     Next session
 Alt + N        Next session
 Alt + P        Prev session
 prefix + w     Tree view

 WINDOWS
 ───────
 prefix + c     New window
 prefix + &     Kill window
 prefix + ,     Rename window
 Alt + n        Next window
 Alt + p        Prev window
 prefix + 0-9   Go to window #
 Ctrl+Shift+←   Move window left
 Ctrl+Shift+→   Move window right

 PANES
 ─────
 prefix + |     Split horizontal
 prefix + -     Split vertical
 prefix + x     Kill pane
 prefix + z     Toggle zoom
 Alt + z        Toggle zoom
 Alt + Arrows   Navigate panes
 prefix + {     Swap pane left
 prefix + }     Swap pane right
 prefix + q     Show pane numbers
 prefix + !     Pane -> window

 RESIZE PANES
 ────────────
 prefix + Shift+Arrows  (repeat)

 SESH
 ────
 prefix + t     Sessions (fzf)
 prefix + T     Sessions+windows
 Alt + w        Sessions (fzf)
 Alt + W        Sessions+windows

 RESURRECT
 ─────────
 prefix + C-s   Save session
 prefix + C-r   Restore session

 COPY MODE
 ─────────
 prefix + [     Enter copy mode
 q              Exit copy mode
 /              Search forward
 ?              Search backward
 Space          Start selection
 Enter          Copy selection
 prefix + e     Scrollback -> nvim
                (bottom)
 E (in copy)    Scrollback -> nvim
                at cursor

 OTHER
 ─────
 prefix + r     Reload config
 prefix + :     Command prompt
 prefix + ?     This cheatsheet

 CREATE/KILL SESSIONS
 ────────────────────
 :new-session -s name
 :kill-session
 prefix + w -> x  Kill from tree

 CHOOSE-TREE (prefix+s / prefix+w)
 ──────────────────────────────────
 Enter   Choose selected
 Up/Down Navigate
 x       Kill selected
 X       Kill tagged
 t       Tag/untag item
 T       Untag all
 C-t     Tag all
 :       Cmd for tagged
 C-s     Search by name
 n       Repeat last search
 f       Filter by format
 O       Change sort field
 r       Reverse sort order
 v       Toggle preview
 < >     Scroll preview
 R       Rename selected
 q       Exit
