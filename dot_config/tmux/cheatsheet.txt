 SESSIONS                          WINDOWS
 ────────                          ───────
 prefix + d     Detach             prefix + c     New window
 prefix + s     List sessions      prefix + &     Kill window
               (sorted by name)    prefix + ,     Rename window
 prefix + S     Pick & rename
 prefix + $     Rename session     Alt + n        Next window
 prefix + (     Prev session       Alt + p        Prev window
 prefix + )     Next session       prefix + 0-9   Go to window #
 Alt + N        Next session       Ctrl+Shift+←   Move window left
 Alt + P        Prev session       Ctrl+Shift+→   Move window right
 prefix + w     Session/window
                tree view

 ─────                             ────

 prefix + -     Split vertical     prefix + T     Sessions+windows
 prefix + x     Kill pane          Alt + w        Sessions (fzf)
 prefix + z     Toggle zoom        Alt + W        Sessions+windows
 Alt + z        Toggle zoom
 Alt + Arrows   Navigate panes     RESURRECT
 prefix + {     Swap pane left     ─────────
 prefix + }     Swap pane right    prefix + C-s   Save session
 prefix + q     Show pane numbers  prefix + C-r   Restore session
 prefix + !     Pane -> window
